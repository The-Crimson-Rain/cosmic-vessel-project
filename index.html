FIREBASE SETUP REQUIRED
This hub uses Firebase for secure logins & real-time sync. It's free. Follow these steps once:
STEP 1 · CREATE PROJECT
Go to console.firebase.google.com → Add project → name it "cosmic-vessel-project" → disable Analytics → Create
STEP 2 · ENABLE AUTH
Build → Authentication → Get started → Enable Email/Password
STEP 3 · CREATE DATABASE
Build → Firestore Database → Create database → Start in test mode → choose nearest region
STEP 4 · GET CONFIG
Project Settings (gear icon) → Your apps → Web app icon </> → Register app → Copy the firebaseConfig object
STEP 5 · PASTE CONFIG BELOW
Paste your Firebase config object into this box:
STEP 6 · FIRST ADMIN ACCOUNT
After saving config, you'll be prompted to create your admin account.
